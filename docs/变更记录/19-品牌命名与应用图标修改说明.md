# 品牌命名与应用图标修改说明

## 变更结论

项目对外名称由开发阶段代号 `LocalForge` 调整为 **RepoForge**，中文名为 **代码锻造**，完整产品副标题为 **代码锻造智能体**。界面标题统一显示为“RepoForge · 代码锻造智能体”。

`Repo` 表示智能体围绕用户明确打开的代码仓库工作；`Forge` 原义为锻造、打造，在本项目中表示把需求通过计划、工具调用、代码修改和验证逐步转化为可审查成果。名称描述的是工作对象与过程，不表示模型在本机离线运行。

## 图标设计

新图标以代码括号包围验证勾为主体：

- 代码括号表示仓库源码和结构化工具操作；
- 验证勾表示修改必须经过测试、结果核验和 Diff 审查；
- 深色底与紫蓝色高光沿用桌面界面的视觉语言；
- 图形不包含文字，在 16、24、32、48、64、128 和 256 像素下仍可辨认。

主矢量文件为 `media/repoforge-icon.svg`，同时提供 Renderer 与窗口使用的 PNG，以及 Windows 打包和快捷方式使用的多尺寸 ICO。开发构建、免安装应用和桌面快捷方式不再使用 Electron 默认图标。

## 兼容边界

本次只调整对外品牌，不迁移已有数据标识：

- GitHub 仓库地址继续使用 `jycschool/localforge-agent`，保留真实提交历史与已有链接；
- 项目 Skill 目录继续使用 `.localforge/skills`；
- `LOCALFORGE_API_KEY`、`window.localForge` 和既有本地存储键继续作为兼容接口；
- `package.json` 的内部包名继续使用 `localforge-agent`，确保开发版仍读取原有用户数据目录。

因此改名不会使已保存的模型配置、API Key、Memory、Skill 选择或任务历史看起来丢失。以后若需要正式发布，再通过独立迁移版本逐步提供新标识和旧标识回退，不在课程演示阶段承担不必要的数据迁移风险。

## 验收标准

1. 顶栏、欢迎页、窗口标题和 Agent 消息使用 RepoForge 品牌。
2. Windows 免安装目录为 `RepoForge-win32-x64`，启动文件为 `RepoForge.exe`。
3. 开发窗口、打包程序和快捷方式均使用自有图标。
4. 原有本地配置和项目 `.localforge` 内容继续可读。
5. 类型检查、自动化测试、构建、交付检查和 Windows 打包全部通过。
