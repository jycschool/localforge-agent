### 第八阶段：模型流式输出

- OpenAI-compatible 请求启用 `stream: true`，逐块解析 SSE；服务仍返回完整 JSON 时继续兼容原有路径。
- 可见 content 通过瞬时 `assistant_delta` 事件实时送往 Renderer；reasoning 只在内存中拼接，不展示、不落盘。
- tool call 按 index 聚合分片的 id、名称和 arguments，完整通过协议校验后才允许 AgentLoop 调度工具。
- 右侧在同一条时间线节点内按动画帧刷新纯文本，最终响应到达后再安全解析 Markdown，避免重复消息和半截 Markdown 跳动。
- 流式增量不写入任务历史，历史只保存最终完整 assistant 消息；停止或失败时保留已收到文本并明确标记未完成。
- 新增 SSE 分块边界、reasoning 隔离、工具调用拼接、无 SSE header 兼容和 Agent 增量事件顺序测试；当前自动化测试增至 73 项。

### 第十五阶段：阻止重复失败的工具循环

- System prompt 同时要求模型收到参数错误后必须修正参数，不能原样重复；新增回归测试后自动化测试增至 82 项。

### 第十六阶段：可执行权限、响应档位与 Token 观察

- 设置新增只读/工作区读写权限；只读模式在创建 ToolRegistry 前移除修改、写入和命令工具，工作区模式保留原逐次命令审批。
- 模型改为预设选择与自定义 Model-Id 并存；快速、标准、深入分别使用 4K、8K、16K 单轮输出预算，界面明确这不是伪造的每秒生成速度。
- ModelClient 解析完整 JSON 或流末尾 usage-only Token 数据；服务不返回 usage 时按消息、工具 schema 和输出做本地估算，始终以 `≈` 区分。
- Agent 状态实时显示累计输入/输出/合计，历史详情保留同一证据；新增权限、usage、估算和输出预算测试后共 16 个测试文件、88 项测试。
- 首次真实问答发现 ModelScope 流末尾返回 0/0/0 usage 占位包，旧实现误标为精确 0 Token；现把全零包视为缺失并回退估算，旧历史显示也会修复。回归测试增至 89 项。

### 第十七阶段：补齐上下文与会话管理闭环

- Skill 弹窗新增新建、读取正文、编辑和二次确认删除；文件仍位于项目 `.localforge/skills`，主进程限制文件名、大小、普通文件和真实目录边界。
- Memory 新增明确的创建/修改文案和二次确认删除；删除会移除项目隔离的本机存储文件、取消启用，并保留空编辑态供立即重建。
- 历史新增“删除会话”；从任一接续记录定位根节点并删除整条后继链，其他会话和项目文件不受影响，活动任务期间禁止删除。
- Preload 与主进程增加对应白名单 IPC 和不可信入参校验；存储、映射与路由测试增至 94 项，用例、设计、原型、数据流和追踪文档同步更新。

### 第十八阶段：建立项目中期生命周期基线

### 第十九阶段：工作区连续性与代码浏览体验

- 根据用户对 P1 体验包的明确批准，同一工作包完成上次授权项目恢复、按项目未发送草稿、`Ctrl+P` 快速打开、代码行号、复制项目内路径/内容和步骤耗尽继续入口；仍保持只读预览，不新增编辑器、终端、数据库或自动模型请求。
- 新增 `WorkspaceStateStore`：只有系统目录选择器成功且扫描完成后才保存根路径；恢复 IPC 不接收 Renderer 路径，失效路径清除后安全回到空白工作台。草稿使用按项目摘要分槽的本机 Renderer 存储，成功启动任务或新建会话后删除。

- 完成真实 Electron 重启验收：`Ctrl+P` 可打开文件，行号与复制按钮布局正常；写入未发送草稿后重启，项目、历史和草稿均恢复，验收草稿随后清除。

### 第二十阶段：运行前透明度、恢复与证据导出

- 设置新增“保存并测试”：使用小型文本请求和固定无副作用工具 schema，分项检查连接、文本、流式输出、Token usage 与原生 tool calling；普通聊天成功不再等同于 Agent 能力可用。
- 任务输入区新增“发送清单”：复用真实运行的 system prompt、历史父链、Skill、Memory、附件和权限过滤，本地展示上下文组成与预计输入 Token，不读取 Key、不请求模型。
- ChangeTracker 快照增加当前内容摘要；Diff 支持二次确认撤销单文件，变更区支持全部撤销。主进程在写回前重新校验摘要，发现任务结束后的外部修改则拒绝覆盖；新建文件按恢复语义删除。
- Memory 弹窗展示最后更新时间、字符数和注入开头，并提供受限文本导入导出；历史详情可导出包含配置、上下文标记、事件与改动路径的 Markdown 证据报告，明确排除隐藏 reasoning 和 Key。
