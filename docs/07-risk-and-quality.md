## 2. 质量属性落实

- **正确性**：文件内容和命令结果来自本地工具，完成摘要引用实际验证。
- **安全性**：Renderer 沙箱、IPC 白名单、项目路径边界、审批、超时和密钥隔离。
- **可恢复性**：工具失败反馈模型；任务失败不自动提交、不回滚用户文件；重启后遗留运行记录显示为意外中断。
- **可解释性**：时间线展示工具、目标、结果，并拆分批准等待与执行耗时；Diff 展示实际变化。
- **可维护性**：模型、循环、工具、桌面服务和 UI 使用明确接口。
- **可移植性**：核心 Agent 不导入 Electron，可在单元测试中独立运行。

## 3. 代码质量门禁

- TypeScript strict 模式，无类型错误。
- 核心安全逻辑和失败路径必须有自动化测试。
- Renderer 不启用 Node 集成，不拼接模型生成的 HTML。
- 外部进程必须有批准、超时、整棵进程树取消、退出码和截断处理。
- 文件扫描跳过依赖、缓存、构建目录和符号链接。
- 新增或变更需求同步更新追踪矩阵、测试和日志。

## 4. 提交与材料合规

- 公开 Git 仓库在题目发布后创建，保留完整真实历史。
- 不改写已推送提交，不伪造开发过程。
- 截止后不向远端推送新提交。
- `README.txt` 不超过 1000 汉字，包含 URL、运行方法和特色。
- MP4 不超过 2 分钟和 200 MB，不出现 Key、用户名或无关个人文件。
- 最终压缩包只放要求的材料，并按题目命名。
