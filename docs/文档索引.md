## 目录职责

| 目录 | 内容规则 |
| --- | --- |
| `产品与需求/` | 当前有效的产品需求与用户用例 |
| `架构与设计/` | 当前设计、数据流、原型和不可改写的 ADR |
| `项目过程/` | 计划、真实开发日志和仍未完成的路线图 |
| `质量与验证/` | 测试、风险、需求追踪和真实模型验证证据 |
| `交付与答辩/` | 视频、考核核对和答辩材料 |
| `变更记录/` | 已批准范围变更的原因、边界和验收说明 |
| `历史归档/` | 已冻结的阶段快照；只补勘误，不更新为当前状态 |
| `文档资源/` | 文档引用的图片与其他静态资源 |

## 维护规则

- 需求变化时同步更新 FR/NFR、用例、设计、测试和追踪矩阵。
- 架构级调整新增 ADR，不覆盖先前真实决策。
- 已完成事实只追加到 `项目过程/09-开发日志.md`；路线图完成后删除对应待办并链接日志，不复制功能清单。
- 测试数量以测试计划为当前口径；历史日志和中期快照保留当时数字，不反向改写。
- 发布前检查文档链接、占位符、凭据、视频和答辩表述是否一致。
- 提交与推送按真实里程碑进行，不伪造日期或用空提交制造开发周期。
