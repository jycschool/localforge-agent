### 第八阶段：模型流式输出

- OpenAI-compatible 请求启用 `stream: true`，逐块解析 SSE；服务仍返回完整 JSON 时继续兼容原有路径。
- 可见 content 通过瞬时 `assistant_delta` 事件实时送往 Renderer；reasoning 只在内存中拼接，不展示、不落盘。
- tool call 按 index 聚合分片的 id、名称和 arguments，完整通过协议校验后才允许 AgentLoop 调度工具。
- 右侧在同一条时间线节点内按动画帧刷新纯文本，最终响应到达后再安全解析 Markdown，避免重复消息和半截 Markdown 跳动。
- 流式增量不写入任务历史，历史只保存最终完整 assistant 消息；停止或失败时保留已收到文本并明确标记未完成。
- 新增 SSE 分块边界、reasoning 隔离、工具调用拼接、无 SSE header 兼容和 Agent 增量事件顺序测试；当前自动化测试增至 73 项。

### 第十五阶段：阻止重复失败的工具循环
