# 测试计划

## 1. 测试目标

验证 LocalForge 能安全、可控地完成本地 coding agent 闭环，并在模型错误、工具错误、用户拒绝或取消时保持一致状态。

## 2. 测试层次

### 2.1 单元测试

- AgentLoop：文本完成、单/多工具调用、工具失败、最大步骤、取消。
- 路径安全：相对路径、绝对路径、`..`、相似前缀目录、符号链接。
- 工具参数：缺失字段、错误类型、超长内容、文件并发变化。
- 命令执行：成功、非零退出、超时、输出截断和取消。
- ModelClient：认证错误、限流、无效 JSON、缺失 tool call id。

### 2.2 集成测试

- 使用临时工作区和脚本化假模型，完成“读文件 - 修改 - 执行测试 - 完成”。
- 首次测试失败后，假模型读取输出、修正文件并再次执行测试。
- 用户拒绝命令后，agent 收到拒绝结果并安全结束。
- 写入前后 ChangeTracker 能提供正确的原内容和变更列表。

### 2.3 VS Code 扩展测试

- 侧边栏能激活、接收消息和恢复空闲状态。
- 活动文件与选区能够加入上下文。
- 审批按钮只影响对应调用，不能重复确认。
- “打开 Diff”显示任务前和当前内容。
- 停止操作取消模型请求和本地进程。

### 2.4 人工验收

在干净的演示项目中执行核心用例三次：

1. 只读解释任务不产生文件变更。
2. 功能开发任务修改源文件和测试，并通过验证。
3. 故意触发一次测试失败，agent 能依据真实错误修复。

## 3. 核心测试用例

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| T-01 | 模型直接返回说明 | run 正常完成，不调用工具 |
| T-02 | 模型请求读取工作区文件 | 返回带行号内容，路径不越界 |
| T-03 | 模型请求精确替换 | 仅匹配一次时成功并记录变更 |
| T-04 | 旧文本不存在或多处匹配 | 拒绝含糊修改并要求重新读取 |
| T-05 | 用户批准测试命令 | 在正确 cwd 执行并返回真实 exit code |
| T-06 | 用户拒绝命令 | 不启动进程，模型收到拒绝原因 |
| T-07 | 命令超过超时 | 进程终止，结果标记 timedOut |
| T-08 | 用户停止运行 | 当前请求和进程取消，UI 回到可继续状态 |
| T-09 | 达到最大步骤 | run 安全终止且保留过程和改动 |
| T-10 | API key 不存在 | 给出设置引导，日志不出现密钥 |
| T-11 | 打开变更 Diff | 左侧为任务前快照，右侧为当前内容 |
| T-12 | 首次测试失败后修复 | 第二次测试通过，摘要如实记录两次结果 |

## 4. 发布门禁

- `npm run check`、`npm test` 和 `npm run build` 全部通过。
- 仓库扫描无 API key、`.env`、大体积日志和临时文件。
- P0 需求全部通过自动或人工验收。
- 演示任务在新克隆环境可复现。
- 视频中展示的状态与真实命令结果一致。
